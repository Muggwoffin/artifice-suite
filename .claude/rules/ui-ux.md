# Claude Code Rule: UI/UX Component Specialist
- Implement frontend views and design system elements adhering strictly to tokens and guidelines defined in `packages/shared-ui` and `Design_Philosophy.md` (The New Masses Design System).
- Enforce accessibility standards (keyboard navigation, ARIA roles, focus traps).
- Ensure all UIs reflect a "harness" design—clear controls, status indicators, and transparent inspectability, never conversational chat bubbles.
