Primary action control, used for the single dominant action in a view (Save, Start review, Run).

```jsx
<Button variant="primary">Start review</Button>
<Button variant="secondary">Cancel</Button>
<Button variant="ghost" size="sm">Skip</Button>
```

Variants: `primary` (ink-bordered, hard-offset paper shadow that turns green and nudges on hover — see Visual foundations), `secondary` (bordered, neutral), `ghost` (no fill/border), `danger` (error-red fill for destructive actions). Sizes: `sm`, `md`.
