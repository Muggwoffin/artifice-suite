# Suite overhaul prototype

Open `index.html` directly in a browser. The prototype has no build step and
makes no external requests. Use the suite switcher at upper left to inspect
Hub, OCR, Draft, Transcribe, and Graph; theme and activity controls are live.
Link directly to a particular mockup with `?app=ocr`, `?app=draft`,
`?app=transcribe`, `?app=graph`, or `?app=hub`.

This is a behaviour and layout prototype, not production application code.
