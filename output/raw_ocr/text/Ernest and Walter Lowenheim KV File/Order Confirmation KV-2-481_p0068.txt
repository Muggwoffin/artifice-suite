9th October, 1941.

Dear [redacted],

If it is at all possible, I should be extremely grateful if you could make a special effort to see soon. It is desirable to speed up enquiries about the L's and so I would like to have all information possible.

Hoping this will not cause you an inconvenience, and thanks for all you have done so far.

Yours sincerely,

for C.W. Sykes.
