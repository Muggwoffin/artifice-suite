Subject:-  Lowenheim Code.

I completed the investigation on the afternoon of the receipt of your letter of June 9th.

THE CODE.

This consists of "Allgemeine Korrespondenz" which is for coding and consists of the "clear" in alphabetical order with the code word opposite, and "Allgemeine Korrespondenz Teil B" which is for decoding and consists of the code words in alphabetical order with the "clear" opposite.

The code is obviously in German and for use in or through Germany. It was probably drawn up in Germany. The several words for Police are reasonably explained by the recurrence of such a word and the consequent extra need for concealment. The Lowenheim's repudiated the suggestion that each code word denoted the police of different countries.

The matter is further complicated by the claim that in many cases the name in "clear" is itself an alias.

INTERROGATIONS.

The men were interrogated separately and given no chance of consultation. I would regret the matter extraneous to the code but for the facts that it served to introduce the subject gently, forms a background to the explanations and may be of interest to Sykes.
