P.F. 49542.

B.4b.2.        W.5a.

As spoken I am attaching a copy of a code (encl. 3 to 69a) found in the possession of internees associated with the Neubeginnen Movement as it seems likely that it may be of some use to the code section of the Censorship. So far as I can judge from a cursory glance, it would be suitable for German Socialist correspondence and I think there is no reason to suspect that it was used for any more suspect a purpose.

18.7.41.

M.J.E. Bagot.
